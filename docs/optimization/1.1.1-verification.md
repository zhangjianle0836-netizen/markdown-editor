`npm run verify` 最终成功：14 项单元测试、前端和主进程类型检查、Vite 7.3.6 生产构建、静态依赖图检查及两个真实 Electron 集成测试。集成测试使用临时用户数据目录和原生对话框桩，覆盖打开与关闭竞态、排队保存、外部文件修改确认、分屏与阅读渲染一致性、代码文本、标题锚点、跨段落搜索与 500 条上限、帮助键盘操作、IPC 拒绝、草稿恢复和 PDF 导出。

macOS arm64 应用及 DMG 使用现有 Developer ID 签名并验证；未配置 Apple 公证凭据，不能视为已公证。Windows/Linux 的 CI 已配置，尚未在本次本地机器上验证。草稿有约 750ms 的备份延迟；大文档解析仍在渲染线程执行；相对路径图片不会自动按 Markdown 文件目录解析。
