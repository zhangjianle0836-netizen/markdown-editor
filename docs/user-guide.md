# Markdown Editor 用户指南

Markdown Editor 是一个预览优先的本地 Markdown 阅读与轻量编辑工具。打开已有文档时默认进入预览模式，新建文档时默认进入编辑模式。

## 功能特性

- 本地文件读取和保存，支持 `.md`、`.markdown`、`.mdown`、`.mkd`、`.txt`
- 预览、编辑、分屏三种视图模式
- GitHub Flavored Markdown，支持表格、任务列表、删除线等语法
- 文档目录、正文搜索、高亮命中和阅读进度
- 未保存更改保护，切换文件、新建、关闭窗口或退出前可选择保存、丢弃或取消
- 通过文件关联双击打开 Markdown 文件
- 本地未保存草稿备份与恢复，以及保存前的磁盘文件冲突确认
- 导出包含当前未保存修改的 PDF

## 快速开始

开发模式：

```bash
npm run electron:dev
```

生产构建：

```bash
npm run electron:build
```

## 基础操作

### 新建文件

点击工具栏“新建”，或使用 `Cmd/Ctrl + N`。新建文件会进入编辑模式，首次保存时会弹出保存对话框。

### 打开文件

点击工具栏“打开”，或使用 `Cmd/Ctrl + O`。如果当前文档有未保存更改，应用会先询问是否保存。

也可以通过系统文件关联直接打开 Markdown 文件。文件大小上限为 10MB，超过后会提示无法打开。

### 保存文件

点击工具栏“保存”，或使用 `Cmd/Ctrl + S`。保存成功后，工具栏状态会显示“已保存”。

### 恢复草稿与保存冲突

停止编辑约 750ms 后，未保存内容会备份到本机应用数据目录。异常退出后再次启动，可选择“恢复草稿”或“丢弃草稿”。恢复的内容显示为未保存，保存时需要重新选择位置，原文件不会自动被覆盖。正常保存或确认丢弃后清除草稿。

草稿不是自动保存功能，最后约 750ms 的修改可能尚未备份。重要文档仍需手动保存，并保留独立备份。

如果保存时发现磁盘上的文件已被其他程序修改或删除，应用会提示“覆盖保存”或“取消”，默认取消。选择覆盖会替换磁盘内容；取消会保留编辑器里的内容，可以先复制内容，再重新打开磁盘版本。当前没有独立的“另存为”按钮，重新选择位置需要创建新文档后粘贴内容再保存。

### 导出 PDF

点击工具栏“导出 PDF”，在系统对话框中选择保存位置。导出使用点击时的当前内容，包含未保存的修改，不会修改 Markdown 源文件或保存状态。取消对话框即可取消导出。

PDF 使用 A4 白底排版，支持中文、表格、代码块、任务列表、图片与链接。图片需使用可访问的 HTTP(S) 地址；相对路径图片不会按源文件所在目录解析。导出期间按钮显示“正在导出…”，完成或失败后会显示提示。

### 切换视图

- 预览：适合阅读已有文档
- 编辑：适合专注修改正文
- 分屏：左侧编辑，右侧实时预览

## 阅读工具

预览模式会在文档顶部显示搜索和阅读进度。输入搜索词后，正文命中会高亮，目录侧栏最多展示 500 个命中项；超过上限时计数会显示 `+`。包含 3 个及以上标题的文档会显示目录。

## 常见问题

### 为什么打开文件后默认是预览？

应用定位是本地轻量阅读和预览，已有文件默认以阅读为先。需要修改时可以切换到“编辑”或“分屏”。

### 空文件可以打开吗？

可以。空文件会正常打开并显示为空白文档。

### 支持自动保存吗？

不会自动保存到原文件。1.1.1 会备份未保存草稿并在下次启动提供恢复选择；请继续使用工具栏“保存”或 `Cmd/Ctrl + S` 保存原文件。

### 支持导出 PDF 或 HTML 吗？

支持 PDF 导出，包含点击时未保存的内容。暂不支持 HTML 导出；“保存”仍生成 Markdown 或纯文本文件。


### 文档会上传到服务器吗？

没有内置云同步或遥测上传。文档和草稿保存在本机；外部链接由系统浏览器打开，远程图片会请求对应地址。需要离线阅读时，请考虑文档包含的外部资源。

### 图片不显示怎么办？

相对路径图片暂不按原文档目录解析。使用可访问的 HTTP(S) 图片地址，并检查网络和图片来源。相同限制也适用于 PDF 导出。

### 帮助面板如何使用？

点击“?” 打开语法帮助，焦点会进入关闭按钮。可用 Tab 导航，按 Escape 或点击关闭按钮返回原位置；帮助打开期间不触发后台文件快捷键。
